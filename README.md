# oriieebgsmile96.github.io

Personal portfolio of **Orieb Alzyuot**, Senior Front-End & Full-Stack Engineer.

**Live:** https://oriieebgsmile96.github.io

- Hand-built HTML, CSS and vanilla JS. No build step and no framework.
- Lavender theme with light, dark and system modes.
- Accessibility drawer (`Ctrl + ,`): text size, contrast modes (yellow, grayscale, invert), reduced motion, readable font, link highlighting, wide spacing, and a large cursor. Preferences persist per visitor.
- Product screenshots captured from the live platforms in `assets/`.
